sciargs

sciargs – scilab command line arguments

Calling sequence

  args=sciargs()

Description

This function returns a vector of character strings containing the arguments of the Scilab command line. First args entry contains the path of the lanched executable file. This function correspond to the getarg function in C langage

See also getenv
