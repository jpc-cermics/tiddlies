tic

tic – start a stopwatch timer

Calling sequence

  tic()

Description

The sequence of commands tic(); operation; toc(); prints the number of seconds required for the operation.

Examples

  tic();
  realtimeinit(1);
  realtime(0);
  realtime(10);
  toc();

See also toc timer etime
