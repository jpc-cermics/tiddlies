who

who – listing of variables

Calling sequence

  who  
  who()  
  names=who('local')  
  [names,mem]=who('local')  
  names=who('global')  
  [names,mem]=who('global')

Description

who displays current variable names.who('local') or who('get') Returns current variable names and memory used in double precision worlds.who('global') returns global variable names and memory used in double precision worlds.

See also whos who_user
