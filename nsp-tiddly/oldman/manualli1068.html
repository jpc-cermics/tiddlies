pvm_gettid

pvm_gettid – returns the tid of the process identified by a group name and instance number

Calling sequence

  [tid] = pvm_gettid(group, inum)

Parameters

  • group: string, string that contains the name of an existing group.
  • inum: string, instance number of the process in the group.
  • tid: integer

Description

pvm_gettid returns the tid of the PVM process identified by the group name group and the instance number inum The returned value tidwill be >= 0 if the call is successful and will be will be < 0 if some error occurs.

Examples

  tid=pvm_gettid("worker",0)

See also pvm_joingroup pvm_getinst
