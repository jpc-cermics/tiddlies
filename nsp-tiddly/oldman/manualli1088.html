pvm_tidtohost

pvm_tidtohost – returns the host of the specified PVM process.

Calling sequence

  [dtid] = pvm_tidtohost(tid)

Parameters

  • tid: integer, task identifier of the PVM process in question.
  • dtid: integer, the tid of the host's pvmd3 or a negative value if an error.

Description

pvm_tidtohost returns the host id on which the process identified by tid is running. The returned value dtidwill be >= 0 if the call is successful and will be will be < 0 if some error occurs.

Examples

  dtid=pvm_tidtohost(pvm_mytid())

See also pvm_config pvm_tasks
