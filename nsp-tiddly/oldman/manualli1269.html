grep

grep – find matches of a string in a vector of strings

Description

Not implemented int Nsp. A similar result is given by function strstr.

Examples

  txt=['The night has a thousand stars';'night train';'a star is born';'naima'];
  // grep(txt,'star');
  e1=find(strstr(txt,'star'))
  // grep(txt,['star' 'night'])
  e2=find(strstr(txt,'night'));
  e3=union(e1,e2);

See also strstr
