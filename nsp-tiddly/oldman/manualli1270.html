justify

justify – Not implemented in Nsp

Description

Not implemented int Nsp. A similar result can be obtained with sprintf.

Examples

  txt=['56','x','night';'1','foo','stars';'2000','z','locomotion'];
  l_txt=m2s([]);
  r_txt=m2s([]);
  [m,n]=size(txt);
  for i=1:n do
    col=txt(:,i);
    len=max(length(col))*ones(m,1);
    l_txt=[l_txt,sprintf('%-*s',len,col)];
    r_txt=[r_txt,sprintf('%*s',len,col)];
  end

See also sprintf
