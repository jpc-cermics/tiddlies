tokenpos

tokenpos – returns the tokens positions in a character string

Description

Not implemented in Nsp. The result can be obtained with strindex.

Examples

  str='The night has a thousand\tstars';
  I=strindex(str,[' ','\t']);
  kdf=[[1;I'+1],[I'-1;length(str)]];
  
  res=m2s([]);
  for i=1:size(kdf,1) do
    res=[res,part(str,kdf(i,1):kdf(i,2))];
  end
  
  res.equal[['The','night','has','a','thousand','stars']]
  res.equal[split(str)]

See also strindex split
