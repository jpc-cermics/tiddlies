tdinit

tdinit – interactive initialisation of the tdcs dynamical systems

Calling sequence

  tdinit()

Description

This macro can be used to interactively define the parameters needed by the dynamical systems described in systems ”bioreactor model” ”competition model” ”system with limit cycle” ”linear system” ”quadratic model” ”linear system with a feedback” ”prey predatory model”
