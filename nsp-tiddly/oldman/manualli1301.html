TCL_ExistVar

TCL_ExistVar – returns true if a tcl variable exists

Calling sequence

  OK=TCL_ExistVar(varname)

Parameters

  • varname: string character Contains the name of the tcl/tk variable.
  • ok: a boolean %T if varname exists.

Description

This routine allows to test if a tcl variable exists .

Examples

  TCL_SetVar('Scilab','OK')
  TCL_GetVar('Scilab')
  TCL_UnsetVar('Scilab')
  TCL_ExistVar('Scilab')
