TCL_UnsetVar

TCL_UnsetVar – remove a tcl variable

Calling sequence

  OK=TCL_UnsetVar(varname)

Parameters

  • varname: string character Contains the name of the tcl/tk variable to unset.
  • ok: a boolean %T if varname deleted.

Description

This routine allows to unset a tcl variable. .

Examples

  TCL_SetVar('Scilab','OK')
  TCL_GetVar('Scilab')
  TCL_UnsetVar('Scilab')
  TCL_ExistVar('Scilab')

See also TCL_ExistVar TCL_SetVar TCL_GetVar
