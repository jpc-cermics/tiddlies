TCL_UpVar

TCL_UpVar – make a link from a tcl source variable to a tcl destination variable

Calling sequence

  OK=TCL_UpVar(varname1,varname2)

Parameters

  • varname1: string character contains the name of the tcl source variable.
  • varname2: string character contains the name of the tcl destination variable.
  • ok: a boolean %T if iti is ok.

Description

make a link from a tcl source variable to a tcl destination variable.

Examples

  TCL_SetVar('Scilab','OK')
  TCL_UpVar('Scilab','ScilabBis')
  TCL_GetVar('ScilabBis')
  TCL_SetVar('Scilab','NOK')
  TCL_GetVar('ScilabBis')
  TCL_SetVar('ScilabBis','modified')
  TCL_GetVar('ScilabBis')
  TCL_GetVar('Scilab')

See also TCL_ExistVar TCL_SetVar TCL_GetVar
