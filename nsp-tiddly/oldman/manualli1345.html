datevec

datevec – Date components

Calling sequence

  V=datevec(DT)  
  [Y,M,D,H,MI,S]=datevec(DT)

Description

V = datevec(DT) converts a serial date number (defined by datenum) to a date vector V having elements [year, month, day, hour, minute, second]. The first five vector elements are integers.[Y, M, D, H, MI, S] = datevec(DT) returns the components of the date vector as individual variables

Examples

  datevec(720840)
  datevec(datenum())

See also datenum calendar
