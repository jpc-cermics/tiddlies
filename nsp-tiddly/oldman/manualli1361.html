ilib_compile

ilib_compile – ilib_build utility: executes the makefile produced by ilib_Make

Calling sequence

  libn=ilib_compile(lib_name,makename)

Parameters

  • lib_name:: a character string, the generic name of the library without path and extension.
  • makename: character string. The path of the Makefile file without extension.
  • libn: character string. The path of the really generated shared library file.

Description

Utility function used by ilib_build This executes the makefile produced by ilib_gen_Make, compiles the C and fortran files and generates the shared library. Shared libraries can then be used with the link and addinter scilab function for incremental linking.

See also addinter link ilib_build ilib_gen_Make ilib_gen_gateway ilib_gen_loader ilib_for_link
