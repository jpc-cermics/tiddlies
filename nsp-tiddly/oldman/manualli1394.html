setlanguage

setlanguage – Sets the internal LANGUAGE value.

Calling sequence

  setlanguage(language)

Parameters

  • language: with language='fr' or 'eng'

Description

setlanguage(language) changes current language in scilab (help, scipad, and menus).

See also LANGUAGE
