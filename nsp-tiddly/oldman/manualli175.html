inttrap – integration of experimental data by trapezoidal interpolation

Calling sequence

  v = inttrap([x,] s)

Parameters

  • x: vector of increasing x coordinate data. Default value is 1:size(y,'*')
  • s: vector of y coordinate data
  • v: value of the integral

Description

computes: Where f is a function described by a set of experimental value:s(i)=f(x(i)) and x0=x(1), x1=x(n) Between mesh points function is interpolated linearly.

Examples

  t=0:0.1:%pi
  inttrap(t,sin(t))
