isequal

isequal – objects comparison

Calling sequence

  t=isequal(a,b)  
  t=isequal(a,b,..)

Parameters

  • a, b , ... : any variables
  • t: boolean

Description

 isequal compares its arguments. If all of them are equals function returns  %t and in the other case it returns  %f .

Examples

  a=[1,2]
  isequal(a,[1,2])
  isequal(a,1)

See also equal less
