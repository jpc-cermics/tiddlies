ldivf

ldivf – left symbolic division

Calling sequence

  ldivf('d','c')

Description

returns the string 'c\d' Trivial simplifications such as '1\c' = 'c' are performed.

Examples

  ldivf('1','1')
  ldivf('a','0')
  ldivf('a','x')
  ldivf('2','4')

See also rdivf addf mulf evstr
