log2

log2 – base 2 logarithm

Calling sequence

  y=log2(x)

Parameters

  • x: vector or matrix

Description

decimal logarithm.If x is a vector log2(x)=[log2(x1),...,log2(xn)].

Examples

  2 .^log2([1,%i,-1,-%i])
