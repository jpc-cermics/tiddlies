mulf

mulf – symbolic multiplication

Calling sequence

  mulf('d','c')

Description

returns the string 'c*d' Trivial simplifications such as '1*c' = 'c' are performed.

Examples

  mulf('1','a')
  mulf('0','a')
  'a'+'b',//Caution...

See also rdivf addf subf
