cont_mat

cont_mat – controllability matrix

Calling sequence

  Cc=cont_mat(A,B)  
  Cc=cont_mat(sl)

Parameters

  • a,b: two real matrices of appropriate dimensions
  • sl: linear system (syslin list)

Description

cont_mat returns the controllability matrix of the pair A,B (resp. of the system sl=[A,B,C,D]).

  Cc=[B, AB, A^2 B,..., A^(n-1) B]

See also ctr_gram contr canon st_ility
