dispfiles

dispfiles – display opened files properties

Calling sequence

  dispfiles([units])

Parameters

  • units: a vector of numbers, the file's logical units. By default all opened files.

Description

dispfiles displays properties of currently opened files.

Examples

  dispfiles()

See also file mopen
