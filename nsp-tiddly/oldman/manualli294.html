manedit

manedit – editing a manual item

Calling sequence

  manedit(manitem ,[editor])

Parameters

  • manitem: character string (usually, name of a function)
  • editor: character string

Description

edit(manitem ,[editor]) opens the file manitem in the editor given by editor. Default editor is Emacs. This function should be customized according to your needs.

Examples

  //manedit('lqg')
