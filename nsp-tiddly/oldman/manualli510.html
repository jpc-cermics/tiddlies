titlepage

titlepage – add a title in the middle of a graphics window

Calling sequence

  titlepage(str)

Parameters

  • str: matrix of strings

Description

titlepage displays the matrix of strings str in the middle of the current graphics window with a font as big as possible.

See also xtitle
