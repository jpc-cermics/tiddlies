winclose

winclose – close windows created by sciGUI

Calling sequence

  winclose(winIds)

Parameters

  • winIds: matrix of integer greater than 0, window identificator.

Description

winclose(winIds) close windows created by sciGUI.

Examples

  //CREATE SOME WINDOWS
  win1=waitbar('This is an example');
  win2=waitbar('HELLO!');
  halt();
  winclose([win1,win2]);
