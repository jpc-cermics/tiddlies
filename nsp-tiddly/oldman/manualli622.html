expm

expm – square matrix exponential

Calling sequence

  expm(X)

Parameters

  • X: square matrix with real or complex entries.

Description

X is a square matrix expm(X) is the matrixexpm(X) = I + X + X^2 /2 + ... The computation is performed by first block-diagonalizing X and then applying a Pade approximation on each block.

Examples

  X=[1,2;3,4]
  expm(X)
  logm(expm(X))

See also logm bdiag coff log exp
