gspec

gspec – eigenvalues of matrix pencil (obsolete)

Calling sequence

  [al,be]=gspec(A,E)  
  [al,be,Z]=gspec(A,E)

Description

This function is now included in the spec function. the calling syntax must be replaced by

  [al,be]=spec(A,E)  
  [al,be,Z]=spec(A,E)

See also spec
