mstr2sci

mstr2sci – character string matrix to character matrix conversion

Calling sequence

  a=mstr2sci(txt)

Parameters

  • txt : character string or string matrix
  • a : character vector or matrix

Description

This function converts a Scilab character string to a vector of characters. Result is the Scilab equivalent for a Matlab string. Caution: mstr2sci has not to be used for hand coded functions.

See also Matlab-Scilab_character_strings
