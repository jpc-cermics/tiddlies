mtlb_eig

mtlb_eig – Matlab eig emulation function

Description

Matlab eig and Scilab spec behave differently in some particular cases:

    • With one input (A) and two outputs (V,D), Matlab and Scilab returned eigen values have opposite signs.

The function [V,D] = mtlb_eig(A) is used by mfile2sci to replace $>$[V,D] = eig(A). This function will determine the correct semantic at run time. There is no replacement possibility for it. Caution: mtlb_eig has not to be used for hand coded functions.
