coffg

coffg – inverse of polynomial matrix

Calling sequence

  [Ns,d]=coffg(Fs)

Parameters

  • Fs: square polynomial matrix

Description

coffg computes Fs^-1 where Fs is a polynomial matrix by co-factors method.Fs inverse = Ns/dd = common denominator; Ns = numerator (a polynomial matrix) (For large matrices,be patient...results are generally reliable)

Examples

  s=poly(0,'s')
  a=[s,s^2+1;s,s^2-1];
  [a1,d]=coffg(a);
  (a1/d)-inv(a)
