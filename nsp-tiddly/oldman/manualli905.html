detr

detr – polynomial determinant

Calling sequence

  d=detr(h)

Parameters

  • h: polynomial or rational square matrix

Description

d=detr(h) returns the determinant d of the polynomial or rational function matrix h. Based on Leverrier's algorithm.

See also det determ
