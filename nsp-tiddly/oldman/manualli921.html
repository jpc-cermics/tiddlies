polfact

polfact – minimal factors

Calling sequence

  [f]=polfact(p)

Parameters

  • p: polynomial
  • f: vector [f0 f1 ... fn] such that p=prod(f)
    • f0: constant
    • fi: polynomial

Description

f=polfact(p) returns the minimal factors of p i.e. f=[f0 f1 ... fn] such that p=prod(f)

See also lcm cmndred factors
