for

for – language keyword for loops

Description

Used to define loops. Its syntax is:  for variable=expression ,instruction, .. ,instruction,end for variable=expression do instruction,   ,instruction,end If expression is a matrix or a row vector, variable takes as values the values of each column of the matrix. Useful example: for variable=n1:step:n2,  ...,end If expression is a list variable takes as values the successive entries of the list. Warning: the number of characters used to define the body of any conditionnal instruction (if while for or select/case) must be limited to 16k.

Examples

  n=5;
  for i=1:n do for j=1:n do a(i,j)=1/(i+j-1);end;end
  for j=2:n-1 do a(j,j)=j;end;a
  for e=eye(3,3) do e,end
  for v=a do write(6,v),end
  for j=1:n do v=a(:,j),write(6,v),end
  for l=list(1,2,'example') do l,end

See also while end do
