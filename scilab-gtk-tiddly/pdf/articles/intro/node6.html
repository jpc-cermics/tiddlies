1.4 Documentation

The documentation is made of this User's guide (Introduction to Scilab) and the Scilab Manual. Both are distributed as Postscript files and generated by a set of Makefiles. In addition, there are reports devoted to specific toolboxes: Scicos (graphic system builder and simulator), Signal (Signal processing toolbox), Lmitool (interface for LMI problems), Metanet (graph and network toolbox). An FAQ is available at Scilab home page (http://www-rocq.inria.fr/scilab) .
